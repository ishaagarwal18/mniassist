Every request carries X-AutoReach-Signature-256 and X-AutoReach-Timestamp. The signature is an HMAC-SHA256 over {{ '{timestamp}.{body}' }} using your signing secret — the same shape Meta uses, so code that already verifies Meta's webhooks works here unchanged. The timestamp is inside the signed material, which is what stops a captured payload being replayed.
